# Slack-emoji-app

## Project Goal
In the Slack, users can add and use custom emojis. Its fun to be able to use them, however, it can be hard to find an exact emoji: you either have to scroll through all the emojis or memorize the exact name for the emoji. 
This repo solves this problems through the use of a Chrome Extension: 

## MVP Scope
The minimal viable product will have the following features: 
- Users can create an emoji group
- Users can add specific emojis from a Slack organization into an emoji group 
- Users can access emojis groups and access their emojis

## Feature Plans
Feature versions will hopefully include the following features:
- User can remove emojis from emoji groups
- Users can delete emoji groups
- The extension is able to accurately detect and alert the user if its running out of storage for the emojis
